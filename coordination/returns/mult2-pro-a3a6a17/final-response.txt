5. Theorem 4.8 裁决

我的独立结论是：

PDF 第 8 页定理 4.8 的显示比较项很可能漏写 1/q_div。这是从定义和相邻引理推出的推断性勘误，不是作者确认的 erratum。

令：

m_i = q_div*a_i + b_i

Tensor2 重组为：

t = q_div*a_1*a_2 + a_1*b_2 + b_1*a_2

于是：

q_div*t = m_1*m_2 - b_1*b_2
t = (m_1*m_2-b_1*b_2)/q_div

RS2 再除以 q_l，组合目标应为：

(m_1*m_2-b_1*b_2)/(q_div*q_l)

极小反例：

q_div=5, q_l=7
m_1=m_2=5
b_1=b_2=0
a_1=a_2=1

Tensor2 recombined     = 5
after RS2              = 5/7
printed theorem target = 25/7
corrected target       = 5/7

这与定义 4.1/引理 4.2 对 q_div 的除法、RS2 对 q_l 的除法，以及定理后“overall scale divided by q_div*q_l”的文字一致。

测试不会用静默修正后的陈述去宣称 PDF 原定理已被证明。

6. 记录尺度、逻辑尺度与解码偏差

令：

Delta_0 = 2^p

输入 degree-2 pair 的记录尺度是：

SF_in = Delta_0^2

最终 Mult2 输出：

SF_out,recorded          = Delta_0^2
SF_out,recombined,logical = Delta_0^4/(q_div*q_l)

因此：

r = logical/recorded
  = Delta_0^2/(q_div*q_l)
  = 2^(2p)/(q_div*q_l)

测试使用实际原生 q_div、实际被 RS2 丢弃的 q_l 计算该比值，不假定二者等于 FIXEDMANUAL 的记录因子 2^p。

供应的 OpenFHE 1.5.0 FIXEDMANUAL DCRT decoder 依据 p 和 noiseScaleDeg 解码，而不是把任意 ciphertext scaling factor 当作最终逻辑尺度。因此普通解码会得到：

decoded_recorded ≈ true_product * r

当前测试的诊断性恢复为：

decoded_logical
    = decoded_recorded / r
    = decoded_recorded * q_div*q_l / 2^(2p)

测试先验证未经校正的结果确实符合预测的确定性偏差，再单独检查逻辑校正后的槽位误差，没有静默修改 expected plaintext。

仅设置 ciphertext 的 recorded SF 不能透明修复该 decoder 路径。产品若要求 RCB -> Decrypt 直接返回逻辑乘积，需要后续增加明确的公开解码辅助接口或公共契约；本次首次 Mult2 切片未越界加入。
