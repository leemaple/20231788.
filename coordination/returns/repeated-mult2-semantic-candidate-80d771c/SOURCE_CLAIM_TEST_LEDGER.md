## What these citations do not establish

A public API declaration and static ownership inspection do not prove successful compilation, cryptographic precision, all-key headroom, security or hosted acceptance. Exact arithmetic validates frozen cleartext expectations, not encrypted execution. The literal kernel check covers bounded coefficient bodies, not every possible upstream effect. Source hashes and patch replay prove byte association and applicability, not semantic GREEN. All such dynamic questions remain the independent Linux/Windows gate in the execution ledger.
