## Specific negative claims this ledger does not make

- It does not claim absence of all secrets merely because scanners returned zero findings.
- It does not claim the current centered headroom proves no wrap for all keys or all histories.
- It does not claim scheme-level raw Poly output has protection equivalent to ordinary Plaintext Decode.
- It does not claim partial strided output equals the current full-Horner observation at `gap=2`.
- It does not claim algorithmic `O(S log S)` complexity establishes paper-scale runtime.
- It does not claim `FIXED_NOISE_DECRYPT` makes encryption, key generation, or the oracle comparison deterministic.
- It does not claim the current N64/HEStd_NotSet diagnostic satisfies paper/security parameters.
