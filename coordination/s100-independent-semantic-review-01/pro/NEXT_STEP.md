# 唯一优先的下一步：对既有单次 fresh 记录作初始误差归因裁定

任务：`S100-INDEPENDENT-SEMANTIC-REVIEW-01`  
审查源码：`a448b787399b43b6024d82c170add403969b493c`  
本次输入没有当前源码的运行结果；下述是结果条件化的一个科学决定，不是已经观察到 A、B 或 C 占主导。

## 1. 决定与边界

**下一步只决定“证据是否支持打开一个初始 I/O 实现缺陷修复切片”。依据是 root 已派发的同源、单次 fresh 记录，而不是再派发实验。若没有 A／C 的可定位实现不一致，就不继续修改 encoder；当 B 主导时，转为核对论文 §6.3 的新鲜公钥加密条件，不能把噪声削小后称为原 S100 修复。**

这是一次有顺序的初始条件归因，不是平行启动编码、采样、Mult2 和安全估计四个项目。该决定的产物是一份可复核的处置记录：所用 source/run 身份、诊断有效性、所选同位置 tuple、支持或不支持哪一种缺陷假设、唯一尚缺的判别证据。

本轮独立审查已经可以交付，无须等待该运行；root 拥有真实运行和日志保全责任。不能预设 B 为主因，也不能把第一 GREEN 的编译失败当成数值观测。

## 2. 先确认“有可解释的记录”，不是先看误差大小

只使用 source=`a448b787399b43b6024d82c170add403969b493c` 对应的完整记录：默认回归和 public API 构建的实际结果、controls 先成功、随后 fresh 恰好调用一次、环境和精确基／尺度身份相符。新的 `2^-300` 构造是否真正编译成功也只能在这里确认。

`INVALID`、超时、编译失败、缺少末尾状态、只有绿色 CTest 摘要而没有完整数值记录，均先登记为 **DIAGNOSTIC_NOT_INTERPRETABLE**。此时不下 A/B/C 因果结论，不把已有部分输出当作完整归因，更不重复抽样直到出现 COMPLETE。缺完整日志尤其要结合 `REVIEW.md` R-03 的最终刷新边界。

以上是使用现有结果的门槛，不是增加试验次数或恢复 1000 次要求。默认回归中既有的其他加密与 setup 中的密钥生成，也不应误计为 fresh payload 的重抽样。

## 3. 同一个决定的条件分支

按下列顺序消费结果；进入一个实质分支后，不并行扩展其他修复方向。

| 既有记录呈现的情况 | 唯一处置 | 什么证据才足以改变处置 |
|---|---|---|
| A 或 C 给出可定位的不一致 | **IMPLEMENTATION_BOUNDARY_FIRST**：先锁定该编码／相位读出边界，不归咎论文噪声。A 是编码误差；C 跨越官方相位路径、生产 forward 与桥接，不能直接命名成 FFT bug。 | 同一多项式、同一槽／分量上的独立定义值与生产值，能定位到具体整数、root/bin、scale 或转换关系；不能只有 A+B+C 的恒等式。 |
| A、C 相对需解释的量级可忽略，而在同位置 tuple 中 B 主导 | **PAPER_FRESH_CONDITIONS_UNRESOLVED**：没有证据要求再改 encoder。只核对论文的新鲜 public-PKE 条件，保留原 S100 的 FAIL。 | 论文实验实现的 χenc／χerr 具体规定与当前官方公钥噪声模型的可比声明；没有它就不把“条件差异”写成已经证实。 |
| A、B、C 均不足以解释所关注的初始精度预算 | **NO_FRESH_REPAIR_EVIDENCE**：本诊断不支持以 fresh-I/O 为修复目标，保留 seam 而不再加改参数。 | 今后若有独立、同源完整链证据，应从首个后续异常边界提出另一个有界任务；本轮不派发它，也不假设旧逐槽轨迹已提供。 |

“可忽略”不是新设一个取代 E80 的验收门。必须同时说明观察一致性的 `2^-300` 量级、生产内部 `2^-120` 的不同含义，以及初始扰动在固定输入上的放大；不能把三个不同精度门混成一个门。

对于 A，一个有明确理论依据的报警信号是：在独立观察可信且数值余量足够时，`|A|` 明显超过条件性 `2^-86`。它表示“精确 inverse＋正确 nearest”的组合前提至少有一个不成立，不自动指出哪行有错。反过来 A 低于此界并不证明所有整数舍入都正确。对只出现在非锚点的异常，应先排除 `REVIEW.md` R-01 的共同槽序观察错误，再归责生产实现。

A、B、C 的全局最大值可以作为各自的上界，但判断抵消或主导必须使用**同一个 `(slot,component)` 的带符号 tuple**。尤其不能把 A 的最大槽、B 的最大槽和 E0 的最大槽拼成一条等式。

## 4. 允许的最小判别计算：已有锚点上的理想平方传播

若需要知道“这个 fresh 初始误差是否已经足以形成终点精度压力”，无需新的加密或 32k 回放。现有 fresh 输出已经给十个锚点的实、虚两份完整 tuple，见 `project/tests/s100_fresh_error_diagnostic_test.cpp:612–613`。为避免事后挑选最有利点，**固定使用已登记的槽 0**，把它作为一个点态见证；不是全槽代表。

从该点的两份 tuple 组成复数，令

\[
\varepsilon=A+B=O(p)-z,
\qquad
G=(z+\varepsilon)^{256}-z^{256}.
\]

G 是“只有这一次初始相位误差、后续八平方完全精确”的反事实终点误差。这里必须用 A+B，而不是未经检查的 E0：**C 是本次读出误差，不是已经写进 ciphertext 的扰动。**

这是一个已公开输入和已输出诊断值上的单点高精度数值／代数后处理，root 可随处置记录保全输入字符串、运算精度和结果；本审查未执行它。不得改用 binary64 抹去诊断所需低位。其一阶近似和一个保守幅度上界为

\[
G\approx256z^{255}\varepsilon,
\qquad
|G|\le256\bigl(|z|+|\varepsilon|\bigr)^{255}|\varepsilon|.
\]

一阶式只能作解释；上界大于 `2^-80` 也不说明实际 G 超标，必要时应看前述直接计算。与冻结门对照时仍使用 `max(|Re G|,|Im G|)`；不得把复数模长、不同位置最大值、或无符号 A/B 之和替换进冻结判据。若相减存在消去，后处理应通过更高精度复核稳定性，而不是把计算不稳定解释成算法噪声。

这个见证能够说明某个已核对槽位的初始扰动是否不可忽略，但**不能证明真实八个 Mult2 的结果**：后续还有 DCP、重线性化、rescale、RCB 的误差和各阶段提升条件；它们也可能与初始误差抵消。槽 0 很小不能排除其他槽异常，G 超门也不是对实际八平方必定 FAIL 的下界。

此外，当前 fresh 是一个新样本，不是原 ed5fd192 历史 E8 的同一密文。禁止将其 G 与旧 E8 配对作已证实的因果分解。本点态计算只帮助决定先查哪个边界，不撤销旧 FAIL，不替代正式 endpoint 运行。

## 5. 若 B 主导，究竟只核对什么

当前官方 OpenFHE 路径已经可以从源码确定：h128 是 secret，public encryption 的 v 则是默认 dense ternary；相位噪声代数上为

\[
e_{\rm pk}v+e_0+e_1s\pmod Q,
\]

并使用当前配置的 `3.19F` 噪声参数。依据及精确行号见 `CLAIM_BOUNDARY.md` §6.4。B 是所选中心 lift 的差嵌入，不是未约减 sampler 多项式的直接读出。

因此唯一需要追问的论文条件是：**§6.3 的 fresh 公钥加密是否采用同样的 v 分布和误差分布／幅度规定，连同其确切输入幅度条件？** 所需证据是原始实验条件说明或可核对的实现定义，不是另一个评审的“看起来合理”。论文只给 h128 和表 3 位数，不能回答这些问题。

若来源证明某项条件不同，可以登记“具体哪一项不等价”，再由任务所有者判断是否需要一个明确披露的论文条件复现任务；**不能默默修改当前不可变 S100 后重新命名为通过**。若条件没有公开或无法从本包确定，正确结论仍是“论文新鲜加密条件未闭合”，而非“当前 sampler 有 bug”或“已经确定只是论文条件不同”。若来源明确相同，则这个条件差异假设被削弱，应保留可定位实现偏差的调查方向，但不以单样本推断完整噪声分布。

安全估计、对长期密钥开放高精度噪声查询的风险、S116 的安全性均不由这一条件对账解决。本次分析只使用专用实验密钥产生的既有受控记录，不要求打印私钥、完整 p／d 或 sampler 内部状态。

## 6. 本步结束时应能留下的结论

可接受的处置结论只有证据支持的那一种：定位到一个具体 I/O 实现不一致；未发现该类不一致、但论文初始条件尚未闭合；或 fresh 不是目前有证据支持的修复靶点。**不允许把 COMPLETE、单点理想传播、另一 profile 的 PASS 或条件性理论界当作原 S100 八平方通过。**

无论进入哪个分支，保持冻结输入、一次 payload encryption、h128、官方采样／公钥加密、S100 精确 Q／尺度、原算术和全槽 `2^-80` 门不变。本步不产生实现补丁，不扩展抽样，不重启 CI。
