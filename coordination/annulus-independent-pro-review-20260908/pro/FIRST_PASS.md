## 4. 论文—代码对应的首轮发现

### P1：实际尺度递推正确；把印刷式当尺度说明会出错

论文 PDF p7 Def4.1、Lemma4.2 及 p8 §4.2 末段表明 Tensor2 的重组量先除 d，RS2 再除实际 q，故物理尺度应为 \(S'=S^2/(dq)\)。`project/src/repeated_mult2.cpp:279–310` 使用 actual-prime 有理数，`double_ckks.cpp:826–1243` 对应 Tensor2/Relin2/RS2/RCB。S8/S0 实际约1.000364850389604，不应改成名义2^100固定尺度。

PDF p8 Thm4.8 的书面目标只写1/q，缺少1/d；已运行纯标量独立反例（N2,h1,d13,q101,Q101909,H10,L0,理想精确Relin）。满足大小条件33801<50954.5；定义给出终点13，印刷目标16900/101，误差15587/101超过102/101；按1/(dq)目标1300/101，误差13/101。这是对**该印刷归一化表述**的反例，不是实际加密样本，也未证明修改一处文字就完成全部引理证明；未显示生产尺度缺陷。

### P2：其他纸面表达需保留限制，不推出代码错

PDF p5 Tensor 的中间项负号与其 (1,s) 解密约定不一致。b=a=b'=a'=s=1时书面内积为0、乘积应为4；官方 `base-leveledshe.cpp:620–659` 及候选正确使用正交叉项。

PDF p8 Lemma4.4 的舍入非可加误差一概写成(0,e)过强。P7,rlk=(3,4),s1，两次 c2=1 与一次 c2=2 的舍入差为(-1,1)。仅反驳这一中间向量等式，不冒称整个最终界限均已被推翻。

### P3：公开 evaluator 数据流未发现秘密补偿

`tests/s100_annulus125_eight_square_test.cpp:161–185,258–310`：Evaluate 的入口只有 plan/cipher；客户端一次建 root key、一次公开 Encrypt；DCP一次、Mult2八次，完成后才首次解密。raw E0/E8观测及 oracle 不回流 evaluator。Family 密钥投影与 reentry 不等于另起 fresh 加密链。相同进程中客户端当然保有私钥；本审查确认的是调用/数据流边界，不是进程级隔离证明。

`src/paper_h128_client_keypair.cpp:193–217` 生成 h128 secret，调用官方 public-key/Encrypt 路径；固定官方默认 sparse h192 与所需h128不一致，使用适配器并非自动意味着低噪声挑钥。所读代码没有挑选低噪声钥的循环、修改sigma/v或把fresh误差用于答案补偿。

### P4：observer 有限证据强，但没有正式数值/整数提升证明

源码的512/768二进制精度 full-slot独立变换、全槽单项式X正负控制、10个Horner锚点及producer交叉比较是有价值的有限控制。它们不能仅由“相符”推出严格舍入界。TSV没有全部初始producer误差列，也没有实际整数phase/完整ciphertext，故不能从TSV独立重放所有observer内部检查与evaluator线性史。

中心化系数的正headroom不是整数提升证明：55模101中心化成−46仍有正余量9，却已经换了整数代表。不能据此声称所有中间计算满足论文整数域无绕回条件。

### P5：一次性门禁可拒绝本run rerun，但不能证明历史上从未重建tag

已对 `check_one_shot_gate.py:event_allowed` 的真实纯函数AST执行合成反例：首次create/attempt1通过；先删同名tag再创建的新run同样会带created=true/forced=false/attempt1，也通过。函数没有历史状态。attempt2被拒绝。

这是**证据/策略边界**，不指控实际新run重建过tag；现有记录支持一条真实样本。不得把“当前run只运行一次的约束”升级成“无外部历史证据的全球唯一保证”。不建议为此新搭平台或追加加密。

### P6：来源/缓存边界

当前workflow静态约束源码相对def248a的src/include/tests/CMake不变，实际记录与版本/字节绑定相符。OpenFHE install为cache hit；包内提供二进制哈希但不含可复验的二进制与完整链接闭包。源码pin、git blob、日志哈希的一致性不等于 runner 签名认证或缓存可重现构建证明。有限接受明确保留此来源假设。
