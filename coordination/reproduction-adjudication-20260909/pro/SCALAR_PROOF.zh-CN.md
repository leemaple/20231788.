## 2. 全槽和的封闭式，但不执行全槽求和

写 s=1024b+256r+k，b=0,…,15，r=0,…,3，k=0,…,255。相位正是 i^r。去除微扰后，a 的模式在每个 quarter 内相同；b 的幅度模式也相同，符号 (−1)^b 在四个 quarter 内固定。因此它们乘 `(1+i−1−i)` 完全抵消。

微扰的一个 quarter 求和为

```
Σ_{k=0}^{255}(1024b+256r+k)=262144b+65536r+32640.
```

其中常数项也抵消，余下

```
65536 Σ_{r=0}^{3} r i^r = 65536 (i−2−3i)=−131072(1+i).
```

十六个 block，乘 2^-75，得到 `Σz=−2^-54(1+i)`。

实系数逆嵌入为

```
a_j=(S/m) Σ_s Re[z_s ξ^(−5^s j)].
```

故 `a_0=(S/m)ΣRe z_s=−2^32`。j=N/2 时，`5^s≡1 mod4`，`ξ^(−5^sN/2)=−i`，`Re(−iz)=Im(z)`，所以 `a_{N/2}=−2^32`。正负号、N/2 归一化都已明确，不能把它写成负的虚部均值。

实际公开 p 对应两项都是 −4294967296；其理想值已是整数，最近舍入无歧义。这只认证两项。固定输入在共轭、相位方面的特殊对称使这两项可封闭求解；不由此推定其他系数。

## 3. 半整数边界与负控

论文约定恰好半整数向下，因此整数 k 的准确原像是 `(k−1/2,k+1/2]`。对闭区间 [l,u]：

* 若 `l>k−1/2` 且 `u≤k+1/2`，该项 CERTIFIED。
* 若 `u≤k−1/2` 或 `l>k+1/2`，该项 REFUTED。
* 其余是 INCONCLUSIVE，不能仅因“相交”就通过。

实现使用 2^-224 网格上的整数端点，signed floor/ceil 均向外。完整 runner 的绿色采用条件进一步要求严格正 margin；即使数学上闭右端点可以通过，零 margin 也暂不作为整包 GREEN，避免在当前精度不能排除真正边界时过度认定。该保守策略可能产生 INCONCLUSIVE，不产生假 PASS。

本轮对 k∈{−3,−1,0,2,2^32} 检查开左、闭右、跨界和 margin；另检查负半整数不使用 ties-away/unsigned 规则。p[0]±1、符号翻转、尺度翻倍负控都在原文件身份核验之后调用分类器。

令 p′=p+1。已采用的当前 cap 与三角不等式给出 `||σ(p′)||/S<R+1/S<127/128`。但理想 a0=−2^32 的区间与 p′[0] 的舍入原像完全分离。因此幅度条件不能蕴含编码对应；这不是现有幅度检查器的 bug，它本来就没有承诺检查 Ecd。

## 4. 条件性八平方编码误差界

只有在所有实际系数都正确最近舍入时，系数误差绝对值≤1/2，故

```
δ := ||σ(p)/S−z||∞ ≤ (1/S) Σ_j 1/2 = N/(2S)=2^-86.
```

这是复数最大模界，因而也支配每个实/虚分量；不需要再乘 √2。令 x=σ(p)/S，由实际 cap，|x|<R，且 |z|≤R+δ。用精确恒等式

```
x^256−z^256=(x−z)Σ_{k=0}^{255}x^(255−k)z^k
```

得到 `|x^256−z^256|≤256(R+δ)^255δ`。与 T=2^-80 比较，其上界比值为 `4(R+δ)^255`；Fraction 精确运算将该有理数夹在

```
[424504491252/10^12, 424504491253/10^12)
```

内，严格小于 1/2。这里没有线性化近似，也没有忽略 η 的高次项。原有 fresh 误差传播分析并未重跑；此处是仅关于理想 Ecd 最近舍入的不同、条件性的确定性预算。

## 5. 独立逆嵌入候选的数学规格（本轮未运行）

把 z_s 放入完整 N 个奇根的 y 数组：`e=5^s mod2N, k=(e−1)/2; y[k]=z_s; y[N−1−k]=conj(z_s)`。这覆盖奇指数子群及其共轭，各位置恰一次。因为

```
y_k = Σ_j (a_j/S) ξ^j exp(2πijk/N),
```

普通负号 DFT 后除 N、乘 ξ^(−j) 和 S 即得实数系数 a_j。候选使用这条普通 DFT，不调用生产 SpecialFFTInv、Boost roots 或生产最近舍入例程，也不对 p 做一次新的编码。

向外区间基本算术及 Machin π / Taylor 小角种子复用已供幅度认证器的原样函数，因此**不独立于旧 cap 的区间原语**；但根方向、逆归一化、Hermitian 完成、从 z 出发和舍入区间验收是本次新检查。不能把复用原语谎称两套完全独立实现。

四个 tiny 正控使用解析谱：N4、N8 的 `c0+c_{N/2}X^(N/2)`，以及 N4 的 X、X³。X/X³ 所需 √2/2 以整数 isqrt 向外包围，不从同一三角例程生成预期，也不使用正反变换 round-trip 当真值。完整 N 还必须包含两个封闭式均值控制及 p0±1 语义负控。完整执行、候选独立数学审核都不在本轮完成声明中。
