Root accepts the process-status part of INTEGRATION_CONTRACT.md as the next
small slice. The user delegated ordinary technical seams. Tests invoke the
actual Bash script in a disposable synthetic project with external executable
fixtures for CTest, Python and (only fault cases) tee. They check fixed CTest
argv, exactly one CTest/finalize, immediate status capture, and exit precedence.
No internal module is mocked and no crypto/full replay is executed.

The wrapper must check the fresh empty real scratch directory and required tools
before starting, set the four endpoint environment values, and preserve source
identity supplied by GitHub. It may select synthetic scope only explicitly for
the fixture harness. The finalizer path is resolved relative to the wrapper,
not an ambient working directory. Missing finalizer stops before CTest.

This slice implements only shell orchestration, not finalization, upload, C++
live wiring, Windows native behavior or CTest timeout recognition. Those remain
independent gates. A fake Python boundary is not evidence that the real finalizer
ran. Source and every actual focused RED/GREEN receipt are retained.
