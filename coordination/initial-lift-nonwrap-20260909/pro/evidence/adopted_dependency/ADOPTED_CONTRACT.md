## 3. 可用于实现与排错的核心关系

下式均在固定 `R=Z[X]/(X^N+1)` 下解释。`Q` 为活动模数乘积，`d` 为 Div，`F=dQ` 为升模基，`P` 为单个辅助素数；`U_p` 是非负代表，中心代表另行标明。当前路径是一塔一分区、unsigned conversion、noiseScale=1，并使用同一家族的相同 evaluation-key 行。

### 普通重线性化不是只加一个简单舍入误差

诚实密钥满足 `B_j+A_j*s=P*theta_j*s²+e_j (mod QP)`。令 `D_j(c)=U_qj(c)`、两坐标原始累加为 `z_i=Σ D_j(c)K_ij`、`r_i=U_P(z_i)`，实际 mod-down 是两坐标分别取 `(z_i-r_i)/P=floor(z_i/P)`。

其相位误差整数为：

```text
nu_Q(c) = (Σ D_j(c)e_j − r_0 − s*r_1) / P
```

分子整除 P 来自密钥方程。两坐标余数都不能遗漏。输入相加改变 digit 代表时，还必须保留 digit carry 引入的项；不能普遍宣称 Relin 可加。

### Relin2 的高部分误差不会再平白乘一次 d

升模后的额外 d 塔为零，因此在一塔一分区下，该 digit 正好为零。使用同一家族的对应密钥行时：

```text
投影到 Q 的 Relin_F(raise_d H) = Relin_Q(dH)
RCB(Relin2(H,L)) = Relin_Q(dH) + Relin_Q(L)       (mod Q，逐坐标)
nu_2 = nu_Q(dH_2) + nu_Q(L_2)
```

不是 `d*nu_Q(H_2)+nu_Q(L_2)`。这里的子脚标 2 指三分量乘积的第三密文分量，不是第二次随机生成的密钥。DCP 补偿在重组时抵消；这不代表高、低成员本身都没有误差。

### 归一化必须同时带上 Tensor、rescale 和 wrap

令相位代表 `M_a=d*h_a+l_a`、`M_b=d*h_b+l_b`，本层 Mult 素数为 `m`：

```text
T* = d*h_a*h_b + h_a*l_b + l_a*h_b
d*T* = M_a*M_b − l_a*l_b
S_next = S_a*S_b/(d*m)
```

终端归一化包含低×低遗漏项、`d*nu_2/(S_a*S_b)`、rescale 项，以及显式的模数绕回整数项。只有证明所需中心代表与无绕回条件，才能删除后者。源码结构检查通过并不自动证明数值没有绕回。

设 `B_K` 是单次 Relin 的系数界、`B_2=2B_K`，`R_m=(1+h)(m−1)/(2m)`、`R_d=(1+h)(d−1)/2`。C25 提供下列高低成员系数界接口：

```text
H_next <= N*H_a*H_b/m + (B_K+R_d)/(d*m) + R_m
L_next <= [N*(H_a*L_b+L_a*H_b)+B_K+R_d]/m + (1+d)*R_m
```

它们通过相容整数代表推导：旧 Q 的整数倍经 rescale 变成 Q/m 的整数倍，最终中心化可消去，因此这两个**系数界**不要求中间相位无绕回。但仍须真实的初始高低系数界；不能把系数中心化的性质扩展成 canonical 范数的收缩定理。完整整数代表论证见两个复核文件。
