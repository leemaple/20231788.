## 当前已采用的依赖——必须带修订使用

请先读 `coordination/relin2-bound-20260908/ADOPTED_CONTRACT.md`，再检查所需原文和源码。三处修订已解决：零 digit carry 是充分而非必要条件；原 M13 全正 h128 仅是抽象见证，新增64正64负见证满足实际符号数量约束但未证PRNG完整可达；C18 不能循环依赖已包含结论的 A07。

当前一塔一分区、单 P、unsigned conversion、ns=1、同家族对应 key 行下，已采用：

```text
nu_Q(c) = (Σ D_j(c)e_j − r0 − s*r1)/P
pi_Q Relin_F(raise_d H) = Relin_Q(dH), F=dQ
RCB(Relin2(H,L)) = Relin_Q(dH)+Relin_Q(L) (mod Q，逐坐标)
nu2 = nu_Q(dH2)+nu_Q(L2)
S_next = S_a*S_b/(d*m)
```

局部 Relin 界很小，但这不是全链 no-wrap/精度认证。C25 的系数递推无需中间相位无绕回，却需要真实初值 A10：

```text
H_next <= N*H_a*H_b/m + (BK+Rd)/(d*m)+Rm
L_next <= [N*(H_a*L_b+L_a*H_b)+BK+Rd]/m+(1+d)*Rm
Rd=(1+h)(d−1)/2, Rm=(1+h)(m−1)/(2m)
```

中心化不增加整数系数绝对值，不代表 canonical 范数收缩。C24 的简化归一化界要求相应输入中心代表与 W=0，原历史链尚未验证。C25 粗 N 因子可能快速放大；不得直接当成实测或绕回必然发生。
