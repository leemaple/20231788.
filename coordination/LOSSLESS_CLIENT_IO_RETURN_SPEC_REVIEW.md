## Findings

1. **P1 — freeze actual key-shape validation before direct primitive calls.** Original `TASK.md:114–116,135–137` requires shape/basis validation and explicit rejection. `PROPOSED_PUBLIC_INTERFACE.md:183–190,247` expressly requires only nonnull key, matching context and nonempty/matching tag; its subsequent component/basis checks concern ciphertexts. These predicates admit an official `PublicKeyImpl(context,"tag")` with zero elements, or an unset private element. Official `src/pke/include/key/publickey.h:60–71` permits the former; `src/pke/lib/schemerns/rns-pke.cpp:171–190` then indexes `pk[0]`/`pk[1]` unchecked, while `199–208` dereferences secret parameters and subtracts tower counts. **Inferred consequence:** a literal implementation of the listed preconditions can reach undefined access/null dereference rather than the promised rejection. Specify pre-call PK length exactly two, nonnull consistent parameters, actual tower count/order/root/format and valid full-Q/prefix relationship; likewise validate the SK element before decryption. Include these malformed-key negatives in the first safe slice. This is a design omission, not an observed crash, and does not require proving an arbitrary key's RLWE relation.

2. **P2 — empty metadata maps do not make Clone transitively immutable.** Original `TASK.md:135–137` requires precise ownership. `PROPOSED_PUBLIC_INTERFACE.md:208–210` and TDD `:156` promise evaluator-clone mutation cannot alter the receipt. Official `src/pke/include/ciphertext.h:390–405` copies elements; `src/core/include/lattice/hal/default/dcrtpoly.h:76–80,374–375` shares mutable `Params`, and `ildcrtparams.h:261–265` publicly mutates that object. Thus a clone can expose the receipt's same basis parameters despite separate coefficients/empty metadata maps. The existing basis snapshot can detect drift, but cannot make the underlying snapshot unchanged. Narrow the guarantee to coefficient/scalar/map isolation under an explicit shared-context/basis nonmutation contract, with drift rejection; do not imply arbitrary clone mutation is isolated or silently introduce a context-deep-copy subsystem.
